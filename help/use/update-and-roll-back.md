# Update a plug-in and roll it back

When a plug-in in the collection has a newer version, update it from its own tab in Starboard. Starboard shows what
is new first, keeps the version you had, and goes back to it by itself if the new one does not work.

## Before you begin

- The plug-in is added. Read [Add your first plug-in](../start/add-your-first-plug-in.md) if it is not.
- Your Starboard password.

## Steps

1. Go to **Settings**, then **Plug-ins**. A plug-in with a newer version has an **Update** chip in **Manage**.
2. Select the plug-in's name to open its tab.
3. In **General**, **Versions**, select **Update to** and the new version.
4. Read **What is new since** your version and **How the update is kept safe**.
5. Enter your Starboard password and select **Update** and the plug-in's name.
6. When the dialog says it is updated, select **Done**.

To go back, select **Roll back to** and the version you had on the same tab, then enter your password and select
**Roll back**.

## Things to note

- Plug-ins that work in the background, such as Direct play, finish or stop what they are doing before the update,
  and carry on after it. Each plug-in's Updates page says what it does.
- Only one earlier version is kept. Rolling back needs no download.
- For an app you can add, such as Seerr, rolling back brings back the older app but not its own data as it was.
- A Starboard with an older plug-in API keeps the version it can run: the catalogue offers it that one.
