# Audio description: Dashboard card

Audio description adds 2 cards you can put on your dashboard. Each starts with a grey band: Audio description's logo and name, a status in words, and when it last changed.

## Audio description

Shows a number, with a few words under it.

- **How often it updates:** every 1 hour while the dashboard is open. Nothing is asked while the browser tab is hidden.
- **Example:** 42 described, of 1,240 films and episodes

## Recently found with audio description

Shows a short list, up to 10 lines.

- **How often it updates:** every 1 hour while the dashboard is open. Nothing is asked while the browser tab is hidden.
- **Example:**
  - Slow Horses: 12 of 18 episodes described

## Add it to your dashboard

1. Select **Edit dashboard**.
2. In **Add a card**, choose the card. Its name ends with (Audio description), such as **Audio description (Audio description)**.
3. Select **Save**.

Audio description must be added and active first. Read [Install](install.md).
