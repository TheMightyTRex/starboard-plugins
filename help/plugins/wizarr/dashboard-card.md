# Wizarr: Dashboard card

Wizarr has no dashboard card. It is a whole app with its own page on your home network.

## Open Wizarr

- On its tab, in **Settings**, then **Plug-ins**, then **Wizarr**, select **Open Wizarr** under **Its web page**.
- In the list in **Settings**, then **Plug-ins**, select **Open** beside Wizarr. It is there while it is active.

Its page opens in a new tab.
