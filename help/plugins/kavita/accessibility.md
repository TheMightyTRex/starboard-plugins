# Kavita: Accessibility

Starboard draws everything Kavita shows in Starboard: its settings, buttons and messages, with the same parts as the rest of Starboard. They follow your **Display** choices: text size, spacing, theme, **High contrast**, underlined links and reduced motion.

## What was checked

- **The plug-in tester:** accessibility passed, checking settings, cards and actions. Starboard runs it before the plug-in is added, every time.
- **Its logo**, an open book, has the text description "Kavita logo" where it is shown without its name. Beside its name, screen readers skip it, so the name is read once.
- **Starboard's own parts** (settings, buttons, dialogs and cards) are checked with axe, a keyboard walk and the reading order in each Starboard release. Read [How Starboard is tested](https://themightytrex.github.io/starboard/help/accessibility/how-starboard-is-tested.html).

## Not checked

- **Kavita's own web page** is made by others. Starboard did not check it for accessibility: not checked.
