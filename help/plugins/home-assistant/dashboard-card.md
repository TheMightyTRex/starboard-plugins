# Home Assistant: Dashboard card

Home Assistant adds 1 card you can put on your dashboard. Each starts with a grey band: Home Assistant's logo and name, a status in words, and when it last changed.

## Home

Shows one line saying whether all is well.

- **How often it updates:** once a minute while the dashboard is open. Nothing is asked while the browser tab is hidden.
- **Example:** Front door: closed. Lounge: 20.5 °C

## Add it to your dashboard

1. Select **Edit dashboard**.
2. In **Add a card**, choose the card. Its name ends with (Home Assistant), such as **Home (Home Assistant)**.
3. Select **Save**.

Home Assistant must be added and active first. Read [Install](install.md).
