# Maintainerr: Dashboard card

Maintainerr has no dashboard card. It is a whole app with its own page on your home network.

## Open Maintainerr

- On its tab, in **Settings**, then **Plug-ins**, then **Maintainerr**, select **Open Maintainerr** under **Its web page**.
- In the list in **Settings**, then **Plug-ins**, select **Open** beside Maintainerr. It is there while it is active.

Its page opens in a new tab.
