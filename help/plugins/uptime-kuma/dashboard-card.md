# Uptime Kuma: Dashboard card

Uptime Kuma has no dashboard card. It is a whole app with its own page on your home network.

## Open Uptime Kuma

- On its tab, in **Settings**, then **Plug-ins**, then **Uptime Kuma**, select **Open Uptime Kuma** under **Its web page**.
- In the list in **Settings**, then **Plug-ins**, select **Open** beside Uptime Kuma. It is there while it is active.

Its page opens in a new tab.
