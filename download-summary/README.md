# Download summary

How much has downloaded today and this week, from what Starboard sees in the queue.

An example Starboard plug-in by TheMightyTRexUK, MIT licence.

## What it may do

- It sees what is downloading.
- It runs one small container (48 MB of memory at most).

## On the dashboard

- **Downloaded today**: a stat card.

## Add it

In Starboard, open **Settings**, **Plug-ins**, **Add a plug-in**, and give this address:

`https://raw.githubusercontent.com/TheMightyTRex/starboard-plugins/main/download-summary/starboard-plugin.json`

Or run `python3 install.py` in this folder.
