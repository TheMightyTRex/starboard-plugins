# Seasonal styles

Two more styles for Display: Winter, in deep green and berry red, and Large and clear, for easy reading.

An example Starboard plug-in by TheMightyTRexUK, MIT licence.

## What it may do

- It adds styles to Display.
## Add it

In Starboard, open **Settings**, **Plug-ins**, **Add a plug-in**, and give this address:

`https://raw.githubusercontent.com/TheMightyTRex/starboard-plugins/main/seasonal-styles/starboard-plugin.json`

Or run `python3 install.py` in this folder.
