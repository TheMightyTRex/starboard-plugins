# Watching now

Who is watching what in Jellyfin right now, with how far through they are.

An example Starboard plug-in by TheMightyTRexUK, MIT licence.

## What it may do

- It uses Jellyfin's key, which Starboard keeps.
- It reaches your home network and the internet.
- It runs one small container (48 MB of memory at most).

## On the dashboard

- **Watching now**: a list card.

## Add it

In Starboard, open **Settings**, **Plug-ins**, **Add a plug-in**, and give this address:

`https://raw.githubusercontent.com/TheMightyTRex/starboard-plugins/main/watching-now/starboard-plugin.json`

Or run `python3 install.py` in this folder.
